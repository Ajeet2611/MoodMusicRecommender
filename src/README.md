# 🎵 Mood-Based Music Recommender (Console Project)

## 📌 Project Overview
This is a simple **Java console-based project** that recommends music based on the user's mood.  
The user selects a mood (like Happy, Sad, Energetic, Relaxed), and the program suggests a playlist of songs accordingly.  

## ✨ Features
- Console-based interaction  
- Different mood options  
- Predefined playlists for each mood  
- Beginner-friendly Java project  

## 🛠️ Technologies Used
- Java (Core Java)  
- OOP Concepts (Classes, Objects, Methods)  
- Collections (ArrayList)
